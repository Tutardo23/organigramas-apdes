# APDES Organigramas — sistema visual

## Referencias

- Interfaz real: plataforma de organigramas APDES de este repositorio.
- Estructura institucional: organigrama provisto por Colegio El Buen Ayre.
- Identidad institucional: APDES, Colegios de Familias.

## Activos

- La aplicación actual no contiene un logotipo oficial dentro de `public`.
- Hasta incorporar el activo oficial, se usa el nombre APDES como texto y no se
  dibuja ni sustituye el logotipo.

## Colores

## Tipografía y forma

- Familia existente: Geist Sans.
- Títulos: peso 800–900.
- Texto funcional: peso 600–700.
- Unidad de espaciado: 8 px.
- Controles: radios de 10–16 px.
- Bordes finos, sombras discretas y superficies planas.

## Reglas de interacción

1. La vista `Estructura` muestra únicamente relaciones jerárquicas.
2. La vista `Relaciones` muestra solo los vínculos directos de una caja elegida.
3. Nunca se dibujan todas las relaciones transversales simultáneamente.
4. La etiqueta de un vínculo abre el editor de ese vínculo y no la tarjeta.
5. Función, Personas y Vínculos se editan en pestañas independientes.
6. Las personas se crean una sola vez por colegio y luego se reutilizan.
7. El Consejo, los comités y los equipos directivos se presentan como órganos
   colegiados, sin imponer un responsable único.
